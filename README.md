# Explainable AI for Clinical Decision Support Systems

Systematic review and empirical evaluation of XAI methods on healthcare
datasets. Implements the taxonomy, models, and evaluation framework
described in the accompanying paper *"Explainable AI for Clinical Decision
Support Systems: A Systematic Review with Empirical Evaluation"*.

The repo covers five datasets across two modalities:

- **Tabular** — Breast Cancer (Wisconsin), Parkinson's Disease (UCI), MIMIC-IV
- **Image** — Skin Cancer (dermoscopic), Cell Cancer (peripheral blood)

Twelve predictive models are benchmarked per tabular dataset (KNN, SVM, RF,
DT, AdaBoost, GBM, XGBoost, LightGBM, EBM, LSTM, GRU, 1D-CNN) and four
pretrained CNNs per image dataset (ResNet50, VGG16, InceptionV3,
EfficientNetB0). Explanations are evaluated with fidelity, interpretability,
stability, and fairness metrics.

## Repo layout

```
xai-cdss/
├── data/                    # datasets (CSVs, MIMIC zip, image folders)
├── preprocess/              # data prep pipelines (mostly MIMIC feature building)
├── ml_models/               # per-dataset model training scripts
├── xai_models/              # explanation-generation notebooks (SHAP, LIME, EBM, Grad-CAM, Saliency)
├── xai_metrics/             # per-dataset metrics pipelines (Infidelity, Complexity, RIS/ROS/RRS, MPRT, IROF, Pixel Flipping, disparity)
├── results/                 # generated by scripts; gitignored
├── environment.yml          # conda environment spec
└── README.md
```

## Setup

Create the conda environment (name: `sok-xai`):

```bash
conda env create -f environment.yml
conda activate sok-xai
```

## Pipeline

Scripts are meant to be run in this order per dataset.

### 1. Preprocess

For MIMIC only. Generates the flat `mimic_demo.csv` / `mimic_full.csv`
from the raw relational tables.

```bash
python preprocess/build_mimic_demo.py
python preprocess/build_mimic_full.py    # only if you have full MIMIC access
```

For cell_cancer only (once images are in place). Turns the flat
class-per-folder layout into the `train/{class}/`, `test/{class}/`
structure that `image_models.py` expects.

```bash
python preprocess/prep_images.py
```

Breast and Parkinson's CSVs need no preprocessing.

### 2. Train models

Each script trains all models 5 times, reports mean ± std for accuracy /
precision / recall / F1, and saves every trained model to
`results/tabular/models_<dataset>/` (or `results/image/models_<dataset>/`)
for later XAI use.

```bash
python ml_models/breast_models.py
python ml_models/parkinson_models.py
python ml_models/mimic_models_demo.py
python ml_models/mimic_models_full.py

# For image models, edit the DATASET constant at the top to switch
# between "skin_cancer" and "cell_cancer", then run:
python ml_models/image_models.py
```

### 3. Generate explanations

Notebooks in `xai_models/` walk through the local explanation methods
per modality:

- `Tabular_xai.ipynb` — SHAP, LIME, EBM on tabular datasets
- `image_XAI.ipynb`   — Grad-CAM, LIME, Saliency Map on image datasets

### 4. Evaluate explanations

Each script in `xai_metrics/` loads a trained model from step 2 and
computes the paper's evaluation metrics on its explanations.

Tabular:
```bash
python xai_metrics/breast_xai.py
python xai_metrics/parkinson_xai.py
python xai_metrics/mimic_xai.py
```

Image:
```bash
python xai_metrics/skin_cancer_xai.py
python xai_metrics/cell_cancer_xai.py
```

Fairness (disparity):
```bash
python xai_metrics/mimic_disparity.py
python xai_metrics/mimic_disparity_postprocess.py
```

Metrics covered:
- **Fidelity** — Infidelity, Faithfulness Correlation, IROF (image), Pixel Flipping (image)
- **Interpretability** — Complexity
- **Stability** — Max-Sensitivity, RIS, ROS, RRS, MPRT
- **Fairness** — Fidelity Disparity, Stability Disparity, Consistency Disparity, Sparsity Disparity
