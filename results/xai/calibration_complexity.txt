================================================================================
Methodology for parameter counts (Part B)
================================================================================

Different model families use different notions of 'parameter'; we report
a natural analog for each family and note the counting method explicitly.

LSTM (Keras): count of scalars in model.trainable_variables
  -> sum(np.prod(v.shape) for v in model.trainable_variables)
  Equivalent to model.count_params() when all layers are trainable.

SVM (sklearn.svm.SVC, RBF kernel): dual-coef entries + intercept
  -> model.dual_coef_.size + model.intercept_.size
  We also report n_support_vectors and n_features for context.

XGBoost (xgboost.XGBClassifier): number of tree leaves
  -> (model.get_booster().trees_to_dataframe()['Feature']=='Leaf').sum()
  Each leaf holds one learned real-valued output. We also report
  n_trees, n_split_nodes, and n_total_nodes for context.

EBM (interpret.glassbox.ExplainableBoostingClassifier): total bin scores
  -> sum(np.asarray(s).size for s in model.term_scores_) + intercept
  Each shape function is a piecewise-constant table over binned input.
  We also report the number of main-effect terms and pairwise terms.

Cross-family caveat: an LSTM's 50,000 float weights are not directly
comparable to an XGBoost's 500 tree leaves or an EBM's 3,000 bin scores.
These numbers characterise the size of the hypothesis space within each
family; they should not be interpreted as an equivalent 'complexity' unit.
